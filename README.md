# Sales Data Analysis

## Project Overview
This project analyzes transaction data from `Sales Analysis.xlsx` to evaluate overall revenue performance, regional sales distribution, product category trends, and customer purchasing patterns.

## Dataset Structure
- **File:** `Sales Analysis.xlsx`
- **Key Fields:** OrderID, Date, Customer, Product, Category, Quantity, Unit Price, Total, Region

## Key Insights & Focus Areas
- **Revenue Performance:** Sales performance and revenue metrics across orders.
- **Regional Breakdown:** Sales distribution across East, North, West, and South regions.
- **Category Trends:** Performance of different product lines and categories.

## Tools Used
- Microsoft Excel
- Data Analysis & Visualization
